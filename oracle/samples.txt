# Samples run under cmd.exe by .github/workflows/cmd-oracle.yml.
#
# Format, one directive or sample per line:
#   # source: TEXT  labels the samples that follow, until the next one.
#   # setup: CMD    runs CMD before the sample, in the file that calls it
#                   (repeatable). The runner's environment is inherited, so
#                   a variable that must be undefined gets `# setup: set p=`.
#   # args: TEXT    arguments passed to the sample file.
#   # line: TEXT    a line placed before the sample line (repeatable), for
#                   samples of more than one line.
#   # anything else is a comment; blank lines are ignored.
#   Any other line is the sample line. It ends the sample, and the setup,
#   args and line directives start afresh. Trailing spaces are kept.
#
# The sample runs in its own batch file, called from a wrapper that records
# the environment before and after it. That file also holds the labels :x
# and :probe, which echo their arguments. More samples go in any file named
# oracle/samples*.txt: the runner reads them all, in name order, then the
# files named oracle/samples*.psv, one sample a line in the form
# `BRANCH | ID | PROBE -> EXPECTED | SCRIPT`, where a literal \n separates the
# lines of SCRIPT and \\ stands for one backslash.
